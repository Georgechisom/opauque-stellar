# opaque-poseidon

A `no_std`, dependency-free Poseidon hash over the BN254 scalar field, byte-for-byte
compatible with circomlib / circomlibjs / the scanner's `poseidon-bn128`. Exposes
`poseidon2` (arity 2) and `poseidon3` (arity 3) over 32-byte big-endian field elements,
backed by a hand-rolled Montgomery field (`src/field.rs`) and circomlib constants
machine-generated by `scripts/gen-poseidon-constants.ts` into `src/constants.rs`.

Correctness is pinned to circomlibjs vectors in `cargo test` (e.g. `Poseidon([1,2])`).

## Why it is not used on-chain

This crate exists to answer Phase 5's gating question: *can the privacy-pool maintain
its commitment Merkle tree on-chain by hashing Poseidon inside the contract?*

The sibling `../poseidon-bench` crate measures the real metered CPU of a depth-N
incremental insertion, run as actual wasm via the Soroban test VM. Result:

| depth (≈ hashes) | CPU instructions | vs 100M/tx cap |
|---|---|---|
| 1 (~3) | ~124M | 1.24× over |
| 8 | ~366M | 3.7× over |
| 16 | ~643M | 6.4× over |
| 20 (~22) | ~782M | 7.8× over |

≈ **40M CPU instructions per Poseidon hash** — even a single deposit's
`label` + `commitment` hashing exceeds Stellar's 100M per-transaction budget, and
reducing tree depth does not help.

**Conclusion:** on-chain Poseidon Merkle insertion is infeasible. The deployed
`privacy-pool` contract therefore does no Poseidon: it publishes the commitment **state
root off-chain** (mirroring the reputation-verifier root pattern) with an on-chain
**custody invariant**, and binds `context` with the cheap host `keccak256`. Trees are
built off-chain in TypeScript (circomlibjs / `frontend/scripts/lib/merkleV2.ts`).

This crate and its benchmark are kept out of the main contract workspace/CI as
reproducible reference evidence. If a future Soroban release adds host-accelerated field
arithmetic, revisit: the bench test (`poseidon_insertion_exceeds_soroban_budget`) will
start failing once a hash fits the budget.

```
cd contracts/opaque-poseidon && cargo test            # vector correctness
cd contracts/poseidon-bench  && cargo test --release  # cost benchmark
```
