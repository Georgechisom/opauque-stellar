# Tabletop Exercise Log

Record of annual incident-response tabletop exercises (see
[`README.md`](README.md#tabletop-exercise)). Append a new dated entry after
each exercise; do not edit past entries except to fix factual errors.

## How to log an exercise

```
## <YYYY-MM-DD>

- Scenario used: <one-line description>
- Participants: <roles, not necessarily names>
- Facilitator: <role>
- Time to draft initial notice: <duration>
- Findings:
  - <what worked>
  - <what didn't / gaps found>
- Follow-up actions filed: <links to tracking issues>
- Template/process changes made as a result: <link to PR, or "none">
```
